NULITE / CONTROL

Połącz urządzenie ESP

To pierwsze uruchomienie panelu. Podaj adres IP płytki ESP8266 w sieci lokalnej. Zapiszemy go w SQLite, więc konfiguracja pozostanie po restarcie i aktualizacji kontenera.

Adres musi prowadzić do endpointu JSON /api/data. Przed zapisaniem panel sprawdzi połączenie.
Konfiguracja jest przechowywana lokalnie w wolumenie danych Dockera. Panel nie zapisuje hasła Wi-Fi ani danych logowania.
